# 웹 구현 범위

2026-11-05 사용자가 목표를 “구현 완수”로 지정해 pen 시안의 후속 구현을 요청했다. 기존 디자인과 문구 수정 요구를 유지한다. 공개 배포는 포함하지 않는다.

## 산출물

- `site/`: 별도 빌드나 패키지 설치 없이 정적 서버에서 실행되는 웹사이트.
- README 원문의 헤드라인, 네 장면의 관람형 터미널 시연, 시연과 서로 연결된 문서.
- 데스크톱과 모바일, 키보드, 동작 줄이기, 문장 복사, URL을 통한 장면·문서 복원.
- 로컬 실행 방법과 요구사항별 검증 기록.

## 검증 기준

| ID | 사용자 행동 | 확인할 결과 |
|---|---|---|
| SHOW | 네 장면을 재생한다 | 역할 구성, 직접 협업, Fable의 진척 판단과 계획 갱신, 팀 간 조율이 시간에 따라 나타난다 |
| PLAYBACK | 정지 후 장면·문서를 오간다 | 정지 상태가 유지되고 읽을 수 있는 장면과 문서를 보여준다 |
| DOCS | 장면의 사용법을 열고 돌아간다 | 같은 주제의 문서와 시연이 연결되고 설치·첫 협업부터 운영까지 설명한다 |
| USABILITY | 모바일·키보드·딥링크·뒤로가기·복사를 쓴다 | 화면이 넘치지 않고 조작과 상태 복원이 동작한다 |
| DELIVERY | 안내된 명령으로 실행한다 | 로컬 미리보기와 정적 배포용 파일을 제공하고 검증의 범위를 명시한다 |

재생 상태는 외부 시계 없이 테스트하고, 화면 연결은 실제 브라우저에서 검증한다. 실제 모델·XSM 세션·메신저는 호출하지 않는다.
