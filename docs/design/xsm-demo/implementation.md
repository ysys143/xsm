# 웹 구현 범위

2026-11-05 사용자가 목표를 “구현 완수”로 지정해 pen 시안의 후속 구현을 요청했다. 기존 디자인과 문구 수정 요구를 유지한다. 공개 배포는 포함하지 않는다.

## 산출물

- `site/`: 별도 빌드나 패키지 설치 없이 정적 서버에서 실행되는 웹사이트.
- README 원문의 헤드라인, 네 장면의 관람형 터미널 시연, 시연과 서로 연결된 문서.
- 데스크톱과 모바일, 키보드, 동작 줄이기, 문장 복사, URL을 통한 장면·문서 복원.
- 로컬 실행 방법과 요구사항별 검증 기록.

## 검증 기준

| ID | 사용자 행동 | 확인할 결과 |
|---|---|---|
| SHOW | 네 장면을 재생한다 | 역할 구성, 직접 협업, Fable의 진척 판단과 계획 갱신, 팀 간 조율이 시간에 따라 나타난다 |
| PLAYBACK | 정지 후 장면·문서를 오간다 | 정지 상태가 유지되고 읽을 수 있는 장면과 문서를 보여준다 |
| DOCS | 장면의 사용법을 열고 돌아간다 | 같은 주제의 문서와 시연이 연결되고 설치·첫 협업부터 운영까지 설명한다 |
| USABILITY | 모바일·키보드·딥링크·뒤로가기·복사를 쓴다 | 화면이 넘치지 않고 조작과 상태 복원이 동작한다 |
| DELIVERY | 안내된 명령으로 실행한다 | 로컬 미리보기와 정적 배포용 파일을 제공하고 검증의 범위를 명시한다 |

재생 상태는 외부 시계 없이 테스트하고, 화면 연결은 실제 브라우저에서 검증한다. 실제 모델·XSM 세션·메신저는 호출하지 않는다.

## 구현 결과

기능 구현 커밋은 `2c933ed`다. 실행은 저장소 루트에서 `node site/serve.mjs`로 한다. 패키지 설치나 빌드는 필요하지 않으며, 자세한 사용·배포 파일 안내는 [site/README.md](../../../site/README.md)에 있다.

- 4개 장면이 실제 시간에 따라 재생된다. 자연어 역할 지정, 워커 간 DM, 팀장의 보고 대조와 보드 갱신, 복수 팀의 합의를 보여준다.
- 8개 문서 주제가 장면과 연결된다. 문서를 읽는 동안에도 같은 플레이어를 사용하며 사용자가 정지한 상태를 유지한다.
- 키보드, 좁은 화면의 역할별 보기, 동작 줄이기, 딥링크와 뒤로가기, 복사와 복사 거부 시 대체 창을 구현했다.
- 상단 보조 설명·작은 링크를 제거하고, 지원 런타임 6종을 웹과 pen 양쪽에 표시했다. 모바일·문서에서도 재현한 예시임을 표시한다.
- 완료 수치는 팀장이 워커 보고를 대조한 이후에 표시한다. xsm이 실제 개발 완료율을 자동 추정한다는 표현은 쓰지 않는다.

## 검증 결과

확인한 환경은 Node.js 24.19.0과 Ego Lite 0.6.1.13의 Chromium 156.0.8078.48이다. 검사 입력에는 새 파일도 포함해 SHA-256을 기록했다. 커밋 뒤에도 실행 입력 13개의 해시가 같은 것을 확인했다.

| 기준 | 실행한 경로와 확인 결과 |
|---|---|
| SHOW | 실제 시계의 자동 장면 전환, 4개 장면의 대화와 보드, 검증 수치와 막힘 표시를 브라우저에서 확인 |
| PLAYBACK | 정지 시 시간 고정, 장면·문서 이동 뒤 정지 유지, 다시 보기 버튼, Enter 재생·정지, 동작 줄이기 설정 확인 |
| DOCS | 8개 문서와 대응 장면, 문서에서 시연으로 복귀, 이전 기록 복원, 목차 링크의 초점 이동 확인 |
| USABILITY | 실제 페이지를 폭 390px·320px의 같은 출처 프레임에서 열어 넘침·메뉴·역할별 보기·방향키·Home·End·새로고침 복원 확인 |
| HERO | 보조 설명·작은 링크가 없고, 6개 런타임 이름이 표시되는 것을 브라우저에서 확인 |
| DELIVERY | 로컬 서버의 HTML·JavaScript·폰트 MIME과 자산 응답, 실행 안내와 정적 파일 구성을 확인 |

검사 명령과 출력 요약:

```text
node --test site/tests/player.test.mjs site/tests/site.test.mjs
tests 11 / pass 11 / fail 0 / skipped 0

node site/tests/verify.mjs --space <owned-space-id>
Node checks and 56 real-browser checks: passed

node site/tests/red-pause.mjs
isolated pause regression: caught (2 assertions fail as intended)

isolated premature-progress-count mutation
progress-count assertion fails as intended
```

로컬 계약 검증은 `xsm-demo-web` 작업의 `WEB` 기준으로 양성 검사와 결함 주입 검사를 함께 실행했다. 계약에 기록한 공간 ID 45는 이 실행 당시의 소유 중인 브라우저 작업 공간이다. 재실행할 때는 자신의 작업 공간 ID로 위 검사기 명령을 사용한다.

검사 예산 확인에서는 단위 파일별 5회 실행이 모두 2초 한도 안에 들었고 대기·변동 판정은 없었다. 정지 처리와 조기 진척 표시를 임시 복사본에서 각각 되돌려 검사가 결함을 잡는 것도 확인했다. 원본은 바꾸지 않았다.

[implementation-results.json](implementation-results.json)에 실행 입력 해시와 56개 브라우저 확인 항목을 보관한다. 원시 로그·화면·실패한 중간 실행은 로컬 `deliverables/xsm-demo-web-20261105/`에 보존하며 Git 추적에서는 제외했다.

## 검증 범위

웹사이트를 Chromium에서 검증했다. 좁은 화면 검사는 실제 사이트의 프레임 너비를 고정한 것으로 물리적인 휴대폰 시험을 뜻하지 않는다. 복사 검사는 OS 클립보드를 바꾸지 않고 Clipboard API 경계에서 전달 문장과 거부 흐름을 확인했다.

초기 실행에서는 관리되는 브라우저 창의 너비 복원, 모바일 입력 에뮬레이션, 프레임 새로고침 완료 신호의 경합 때문에 검사기가 실패했다. 너비를 고정한 실제 페이지와 `load` 완료 신호로 수정했고, 최종 검사는 위 항목을 생략하지 않고 모두 실행했다. 시각 검토에서 발견한 메시지 페이드도 제거해 정지 장면을 즉시 읽을 수 있게 했다.

공개 배포는 수행하지 않았다. 로컬 실행과 정적 호스팅용 파일을 제공한다.
