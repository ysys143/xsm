# 브라우저 언어와 여백 조정

사용자의 한국어 자동 표시 요청과 두 스크린샷의 여백 피드백을 함께 반영했다.

- 언어는 URL의 `lang` 지정, 저장된 수동 선택, 브라우저의 지원 가능한 선호 언어 순서로 고른다. 한국어 브라우저의 첫 방문은 한국어이며, 지원하지 않는 언어는 영어로 표시한다. IP나 지역 정보는 사용하지 않는다.
- 메뉴·접근성 라벨·시연의 설명과 사람 간 대화·문서 8개·복사 안내를 한국어로 제공한다. 명령·프로토콜 식별자와 기계가 출력하는 상태 문자열은 원래 표기를 유지한다.
- 언어를 바꿔도 현재 문서·장면·시간·정지 상태를 유지한다. 선택한 언어는 기능용 `xsm.locale` 값으로만 브라우저에 저장하며, 저장이 차단되면 URL로 선택을 유지한다.
- 기존 README의 메시지 채널 문구를 한국어 표제로 사용한다. 앞서 거부된 광고 문구를 다시 쓰지 않는다.
- 설명 박스의 위아래 여백은 48px, 시작하기 구간은 64px로 늘렸다. 문서 열 사이 간격은 넓은 화면 56px이며, 본문은 68ch를 넘기지 않는다. 좁은 화면은 20~24px의 좌우 여백을 유지한다.

로컬 검증에서는 단위 검사 20개, 기존 영어 동작 73개와 한국어·언어 선택·두 언어 여백 30개가 통과했다. 번역 데이터와 영어 데이터의 경로·시간·메시지 식별자를 비교하고, Pages에 필요한 새 모듈이 배포 목록에 있는지 확인한다. 검사 입력 해시와 원시 결과는 `deliverables/xsm-i18n-20261105/`에 보관한다.

```sh
node --test site/tests/player.test.mjs site/tests/site.test.mjs site/tests/i18n.test.mjs
node site/tests/verify.mjs --space <owned-space-id> --output deliverables/xsm-i18n-20261105/verified
```

웹사이트는 기존 Pages 워크플로로 배포한다. 한국어 직접 링크는 `https://ysys143.github.io/xsm/?lang=ko`, 영어 직접 링크는 `https://ysys143.github.io/xsm/?lang=en`이다.
