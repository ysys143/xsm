# 터미널 출력·영어·문단 간격 수정

사용자의 세 가지 요청을 함께 반영했다.

| 요청 | 반영 |
|---|---|
| 실제 터미널 출력에 가깝게 | 고정폭 글꼴, 프롬프트, 런타임별 MCP 호출·결과, XSM 수신 헤더. 보드는 CLI의 Markdown 출력 형태. 출력이 늘어나면 터미널 안에서 스크롤하며 사용자가 이전 로그를 읽으면 자동 추적을 멈춘다. |
| 전부 영어로 | 내비게이션·CTA·접근성 라벨·시연·복사·오류 안내·문서 8개. 외부 조직 안내도 영어 README로 연결한다. pen 표시 텍스트도 영어로 바꿨다. |
| 문단 간격 확대 | 문단 20px, 소제목 구간 일반 화면 48px·좁은 화면 40px. 예시 요청과 다음 섹션도 분리했다. |

현재 xsm의 MCP 인자 스키마와 출력 코드를 참고했다. 도구 호출과 결과는 예시 재현이며 실제 새 에이전트 세션을 실행하지 않았다. 메시지 저장과 과제 완료를 혼동하지 않도록 전송 결과는 `sent-unconfirmed: queued` 형식으로 보여준다.

## 검증 방법

```sh
node --test site/tests/player.test.mjs site/tests/site.test.mjs
node site/tests/red-pause.mjs
node site/tests/verify.mjs --space <owned-space-id> --output deliverables/xsm-terminal-en-20261105/verified
```

기존 4개 시연·8개 문서·재생·탐색 검사에 더해 다음을 확인한다.

- 도구 인자는 한 번에 표시하고 완료 이후 결과가 나타난다.
- 웹 소스와 실제 표시된 문서에 번역되지 않은 한국어가 없다.
- 터미널의 고정폭 글꼴과 MCP 표기, 보드의 셸 명령·Markdown 출력을 확인한다.
- 문서의 실제 계산된 간격을 확인한다.
- 900px·1440px에서도 터미널이 아래 재생 컨트롤과 겹치지 않는다. 390px·320px 검사도 유지한다.

이 수정본의 원시 검사 결과와 입력 해시는 로컬 `deliverables/xsm-terminal-en-20261105/verified/`에 남긴다. 이전 [implementation-results.json](implementation-results.json)은 앞선 구현 커밋의 검증 이력이다.

단위 검사 13개가 통과했다. 별도 임시 복사본에 한국어 메뉴를 넣거나 도구 결과를 완료 전에 표시하도록 바꾸면 각각 해당 검사 1개가 실패했다. 단위 파일별 5회 예산 검사도 2초 안에 통과했다. pen 표시 텍스트의 한국어와 레이아웃 문제는 각각 0건이며, 영어·터미널 출력을 반영한 미리보기 6개를 다시 내보냈다.
